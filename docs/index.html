Integración de Widgets (`wisbe_landingPage` & `wisbe_catalogo`)

Copia estos códigos para incrustar la Landing Page o el Catálogo en cualquier sitio web externo con solo poner una etiqueta personalizada.

Widget Landing Page (`wisbe_landingPage`)

Pega esta etiqueta personalizada HTML en el sitio del cliente para renderizar la Landing Page completa de forma automática.

<wisbe_landingPage business="solaris-power"></wisbe_landingPage> <script src="https://wisbe-platform.com/widget.js"></script>

Widget Catálogo (`wisbe_catalogo`)

Pega esta etiqueta personalizada HTML para integrar el catálogo 100% customizable en cualquier web.

<wisbe_catalogo business="solaris-power"></wisbe_catalogo> <script src="https://wisbe-platform.com/widget.js"></script>
